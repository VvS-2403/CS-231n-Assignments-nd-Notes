# Chapter 8: Generalization

## Introduction
This chapter discusses tools to analyze and understand the **generalization** of machine learning models, i.e., their performance on unseen test examples.

For supervised learning problems, given a training dataset $\{(x^{(i)}, y^{(i)})\}_{i=1}^n$, we typically learn a model $h_\theta$ by minimizing a loss/cost function $J(\theta)$ which encourages $h_\theta$ to fit the data.
For example, with the least squares loss (mean squared error), the training loss/error/cost is:
$$J(\theta) = \frac{1}{n} \sum_{i=1}^n (y^{(i)} - h_\theta(x^{(i)}))^2$$

The ultimate goal, however, is to minimize the **test error**, which is the loss on unseen test examples. We sample a test example $(x, y)$ from the test distribution $\mathcal{D}$, and measure the model's error (e.g., $(h_\theta(x) - y)^2$). The expected loss over the randomness of the test example is the **test loss/error**:
$$L(\theta) = \mathbb{E}_{(x,y)\sim \mathcal{D}}[(y - h_\theta(x))^2]$$

> [!NOTE] Empirical vs. Population Distribution
> - Uniform distribution over the training set is denoted by $\hat{\mathcal{D}}$ (empirical distribution).
> - $\mathcal{D}$ is the population distribution.
> - Training loss = empirical loss/risk/error.
> - Test loss = population loss/risk/error.

Even if training and test datasets are drawn from the same distribution $\mathcal{D}$, the test error may not be close to the training error (the difference is the **generalization gap**). 

- **Overfitting**: Model predicts accurately on the training set (small training error) but doesn't generalize to test examples (large test error).
- **Underfitting**: Model has a relatively large training error (and thus typically a large test error).

## 8.1 Bias-Variance Tradeoff

Consider a training and test dataset where inputs $x^{(i)}$ are chosen randomly and outputs are generated by:
$$y^{(i)} = h^\star(x^{(i)}) + \xi^{(i)}$$
where $h^\star(\cdot)$ is the true quadratic function (ground truth) and $\xi^{(i)} \sim \mathcal{N}(0, \sigma^2)$ is observation noise. A test example also follows $y = h^\star(x) + \xi$ with $\xi \sim \mathcal{N}(0, \sigma^2)$.

### Underfitting & Bias
- **Linear Model Example**: Fitting a linear model $y = \theta_0 + \theta_1 x$ fails to accurately predict $y$ from $x$ on both training and test datasets.
- The true relationship is not linear; any linear model is far from $h^\star(\cdot)$. This causes a large training error (**underfitting**).
- More training data (even infinite) or noiseless data won't fix this because the linear model fundamentally lacks the capacity to represent the true quadratic function.
- **Bias**: Informally, the test error of a model even if fitted to an infinitely large training dataset. The linear model suffers from large bias.

### Overfitting & Variance
- **5th-Degree Polynomial Example**: Fitting a 5th-degree polynomial yields zero training error but large test error. The model captures spurious patterns from the finite training set (due to noise $\xi^{(i)}$). This is **overfitting**.
- The bias is small (a 5th-degree polynomial can represent a quadratic function if given infinite data).
- **Variance**: The amount of variation across models learned on multiple different training datasets drawn from the same distribution. The spurious patterns are specific to the randomness of the noise and inputs in a particular dataset, leading to very different learned models.

### The Tradeoff
- **Simple models** (few parameters): Large bias, small variance (prone to underfitting).
- **Complex models** (many parameters): Small bias, large variance (prone to overfitting).
- **Optimal Tradeoff**: A quadratic model achieves small training and test errors, providing the best balance between bias and variance. The test error curve is typically convex with respect to model complexity.

### 8.1.1 A Mathematical Decomposition (for Regression)

**Setup:**
- Training dataset $S = \{(x^{(i)}, y^{(i)})\}_{i=1}^n$ with $y^{(i)} = h^\star(x^{(i)}) + \xi^{(i)}$, $\xi^{(i)} \sim \mathcal{N}(0, \sigma^2)$.
- Train a model $\hat{h}_S$ on $S$.
- Test example $(x, y)$ where $y = h^\star(x) + \xi$, $\xi \sim \mathcal{N}(0, \sigma^2)$.
- Expected test error (Mean Squared Error) over randomness of $S$ and $\xi$:
  $$\text{MSE}(x) = \mathbb{E}_{S, \xi}[(y - \hat{h}_S(x))^2]$$

**Claim 8.1.1**: If $A$ and $B$ are independent real random variables and $\mathbb{E}[A]=0$, then $\mathbb{E}[(A+B)^2] = \mathbb{E}[A^2] + \mathbb{E}[B^2]$.
*(Corollary: if $c$ is a constant, $\mathbb{E}[(A+c)^2] = \mathbb{E}[A^2] + c^2$. Proof expands the square and uses $\mathbb{E}[AB] = \mathbb{E}[A]\mathbb{E}[B]=0$.)*

Applying the claim with $A=\xi$ and $B=h^\star(x) - \hat{h}_S(x)$:
$$\begin{aligned}
\text{MSE}(x) &= \mathbb{E}[(y - \hat{h}_S(x))^2] = \mathbb{E}[(\xi + (h^\star(x) - \hat{h}_S(x)))^2] \\
&= \mathbb{E}[\xi^2] + \mathbb{E}[(h^\star(x) - \hat{h}_S(x))^2] \\
&= \sigma^2 + \mathbb{E}[(h^\star(x) - \hat{h}_S(x))^2]
\end{aligned}$$

Define the **average model** $h_{\text{avg}}(x) = \mathbb{E}_S[\hat{h}_S(x)]$. This is a hypothetical model trained on an infinite number of datasets.

Further decomposing by letting $c = h^\star(x) - h_{\text{avg}}(x)$ and $A = h_{\text{avg}}(x) - \hat{h}_S(x)$:
$$\begin{aligned}
\text{MSE}(x) &= \sigma^2 + \mathbb{E}[(h^\star(x) - \hat{h}_S(x))^2] \\
&= \sigma^2 + (h^\star(x) - h_{\text{avg}}(x))^2 + \mathbb{E}[(h_{\text{avg}}(x) - \hat{h}_S(x))^2]
\end{aligned}$$
Thus:
$$\text{MSE}(x) = \underbrace{\sigma^2}_{\text{unavoidable noise}} + \underbrace{(h^\star(x) - h_{\text{avg}}(x))^2}_{\text{bias}^2} + \underbrace{\text{var}(\hat{h}_S(x))}_{\text{variance}}$$

- **Bias**: Error due to the lack of expressivity of the model class, fundamentally unable to approximate $h^\star$. 
- **Variance**: Error due to the model's sensitivity to the random nature of the finite dataset. Decreases as dataset size increases.
- **$\sigma^2$**: Unavoidable error, irreducible noise.

> [!NOTE] 
> The bias-variance decomposition for classification is less clear; no single formalism is universally agreed upon.

## 8.2 The Double Descent Phenomenon

### Model-Wise Double Descent
Contrary to the classical U-shaped bias-variance tradeoff curve, recent works demonstrate that test error can present a **double descent** phenomenon (observed in linear models and deep neural networks).
- As model complexity increases, test error first decreases, then increases to a peak (around when the model is just large enough to perfectly fit the training data).
- After the peak, in the **overparameterized regime** (number of parameters > number of data points), the test error decreases again.

> [!INFO] Figure 8.10 Description
> Model-wise double descent: As # parameters increases, test error goes down, up (peak at interpolation threshold), and then down again into the modern over-parameterization regime.

### Sample-Wise Double Descent
- A priori, more training examples should monotonically decrease test error. However, test error peaks when the number of examples $n$ is roughly equal to the number of parameters $d$ ($n \approx d$). 
- This indicates the sub-optimality of the learning procedure when $n \approx d$. With optimally tuned regularization, the peak can be mitigated.

> [!INFO] Figure 8.11 Description
> Left: Sample-wise double descent peaking around $n \approx d$. Right: Optimal regularization $\lambda$ (green curve) eliminates the peak, monotonically decreasing test error as samples increase.

### Explanation and Implications
- **Peak mitigation**: The peak at $n \approx d$ suggests that sub-optimal learning algorithms are to blame. Optimal regularization resolves it.
- **Second descent explanation**: Why do overparameterized models generalize well? A typical explanation is that optimizers like gradient descent provide an **implicit regularization** effect. Even unregularized, gradient descent finds a minimum norm solution that fits the data well when $n \ll d$.
- **Complexity measures**: The number of parameters might not be the best complexity measure. If plotted against the *norm* of the learned model, the test error behaves closer to conventional wisdom (no double descent). The norm itself peaks at $n \approx d$.

> [!INFO] Figure 8.12 Description
> Left: Double descent against # parameters. Middle: Model norm peaks at $n \approx d$. Right: Test error plotted against the norm shows a traditional curve instead of double descent.

## 8.3 Sample Complexity Bounds (Optional Readings)

### 8.3.1 Preliminaries

**Two Useful Lemmas:**
1. **The Union Bound**: Let $A_1, A_2, \ldots, A_k$ be $k$ different events.
   $$P(A_1 \cup \cdots \cup A_k) \le P(A_1) + \ldots + P(A_k)$$
2. **Hoeffding Inequality (Chernoff Bound)**: Let $Z_1, \ldots, Z_n$ be $n$ i.i.d random variables drawn from Bernoulli($\phi$). Let $\hat{\phi} = \frac{1}{n}\sum_{i=1}^n Z_i$. For any $\gamma > 0$:
   $$P(|\phi - \hat{\phi}| > \gamma) \le 2 \exp(-2\gamma^2 n)$$
   This means the empirical mean is a good estimate of the true mean with high probability if $n$ is large.

**Setup for Binary Classification ($y \in \{0, 1\}$):**
- Training set $S = \{(x^{(i)}, y^{(i)})\}_{i=1}^n$ drawn i.i.d from $\mathcal{D}$.
- **Training Error (Empirical Risk)**:
  $$\hat{\varepsilon}(h) = \frac{1}{n} \sum_{i=1}^n \mathbb{1}\{h(x^{(i)}) \ne y^{(i)}\}$$
- **Generalization Error**:
  $$\varepsilon(h) = P_{(x,y)\sim \mathcal{D}}(h(x) \ne y)$$

**Empirical Risk Minimization (ERM)**:
- Hypothesis class $\mathcal{H}$: The set of all classifiers considered by the algorithm (e.g., linear classifiers $\mathcal{H} = \{h_\theta : h_\theta(x) = \mathbb{1}\{\theta^T x \ge 0\}\}$).
- ERM picks the hypothesis:
  $$\hat{h} = \arg\min_{h \in \mathcal{H}} \hat{\varepsilon}(h)$$

### 8.3.2 The Case of Finite $\mathcal{H}$

Assume $\mathcal{H} = \{h_1, \ldots, h_k\}$ is finite (size $k$).

For a fixed $h_i$, let $Z_j = \mathbb{1}\{h_i(x^{(j)}) \ne y^{(j)}\}$. These are i.i.d Bernoulli random variables with mean $\varepsilon(h_i)$. The training error $\hat{\varepsilon}(h_i)$ is their empirical mean.
By Hoeffding's inequality:
$$P(|\varepsilon(h_i) - \hat{\varepsilon}(h_i)| > \gamma) \le 2 \exp(-2\gamma^2 n)$$

To guarantee this for **all** $h \in \mathcal{H}$ simultaneously, let $A_i$ be the event $|\varepsilon(h_i) - \hat{\varepsilon}(h_i)| > \gamma$. Using the Union Bound:
$$\begin{aligned}
P(\exists h \in \mathcal{H}. |\varepsilon(h) - \hat{\varepsilon}(h)| > \gamma) &= P(A_1 \cup \cdots \cup A_k) \\
&\le \sum_{i=1}^k P(A_i) \\
&\le 2k \exp(-2\gamma^2 n)
\end{aligned}$$
Subtracting from 1 gives a **uniform convergence result**:
$$P(\forall h \in \mathcal{H}. |\varepsilon(h) - \hat{\varepsilon}(h)| \le \gamma) \ge 1 - 2k \exp(-2\gamma^2 n)$$

**Sample Complexity:**
To ensure uniform convergence with probability at least $1-\delta$:
$$2k \exp(-2\gamma^2 n) = \delta \implies n \ge \frac{1}{2\gamma^2} \log \frac{2k}{\delta}$$
The number of training examples needed is only logarithmic in $k$.

Solving for $\gamma$:
$$|\hat{\varepsilon}(h) - \varepsilon(h)| \le \sqrt{\frac{1}{2n} \log \frac{2k}{\delta}}$$

**Generalization Bound for ERM:**
Assuming uniform convergence holds (bound is bounded by $\gamma$):
Let $h^\star = \arg\min_{h \in \mathcal{H}} \varepsilon(h)$ (best possible hypothesis in $\mathcal{H}$).
$$\begin{aligned}
\varepsilon(\hat{h}) &\le \hat{\varepsilon}(\hat{h}) + \gamma \\
&\le \hat{\varepsilon}(h^\star) + \gamma \\
&\le \varepsilon(h^\star) + 2\gamma
\end{aligned}$$
*(Using: uniform convergence, ERM minimizes $\hat{\varepsilon}$, uniform convergence again).*

> [!IMPORTANT] Theorem for Finite $\mathcal{H}$
> Let $|\mathcal{H}| = k$. With probability at least $1-\delta$:
> $$\varepsilon(\hat{h}) \le \left( \min_{h \in \mathcal{H}} \varepsilon(h) \right) + 2 \sqrt{\frac{1}{2n} \log \frac{2k}{\delta}}$$
> **Bias-Variance connection**: Enlarging $\mathcal{H}$ to $\mathcal{H}'$ decreases the bias (first term) but increases the variance (second term, dependent on $k$).

For $\varepsilon(\hat{h}) \le \min_{h \in \mathcal{H}} \varepsilon(h) + 2\gamma$ to hold with prob $1-\delta$, we need:
$$n \ge O\left(\frac{1}{\gamma^2} \log \frac{k}{\delta}\right)$$

### 8.3.3 The Case of Infinite $\mathcal{H}$

For infinite hypothesis classes (e.g., parameterized by real numbers), $k = \infty$.

**Informal Argument:**
Using 64-bit double-precision floats, a model with $d$ parameters has at most $k = 2^{64d}$ hypotheses.
$$n \ge O\left(\frac{1}{\gamma^2} \log \frac{2^{64d}}{\delta}\right) = O_{\gamma,\delta}(d)$$
This correctly suggests that the number of training examples needed is roughly linear in the number of parameters $d$. However, this is unsatisfying as it relies on float parameterizations.

**Formal Argument via VC Dimension:**
- **Shattering**: A hypothesis class $\mathcal{H}$ **shatters** a set of points $S = \{x^{(1)}, \ldots, x^{(D)}\}$ if $\mathcal{H}$ can realize any possible labeling on $S$.
- **Vapnik-Chervonenkis (VC) Dimension**: $VC(\mathcal{H})$ is the size of the largest set that is shattered by $\mathcal{H}$.

> [!TIP] VC Dimension Example
> A linear classifier in 2D ($\mathcal{H} = \{h(x) = \mathbb{1}\{\theta_0 + \theta_1 x_1 + \theta_2 x_2 \ge 0\}\}$) can shatter a set of 3 points (yielding 8 labelings). It cannot shatter any set of 4 points. Thus, $VC(\mathcal{H}) = 3$.
> Note: To prove $VC(\mathcal{H}) \ge D$, you only need to show **at least one** set of size $D$ that can be shattered. (e.g., 3 collinear points cannot be shattered, but we only needed one non-collinear set of 3 points).

> [!IMPORTANT] Vapnik's Theorem
> Let $D = VC(\mathcal{H})$. With probability at least $1-\delta$, for all $h \in \mathcal{H}$:
> $$|\varepsilon(h) - \hat{\varepsilon}(h)| \le O\left( \sqrt{\frac{D}{n} \log \frac{n}{D} + \frac{1}{n} \log \frac{1}{\delta}} \right)$$
> Thus, with probability at least $1-\delta$:
> $$\varepsilon(\hat{h}) \le \varepsilon(h^\star) + O\left( \sqrt{\frac{D}{n} \log \frac{n}{D} + \frac{1}{n} \log \frac{1}{\delta}} \right)$$

**Corollary:**
For $|\varepsilon(h) - \hat{\varepsilon}(h)| \le \gamma$ to hold for all $h \in \mathcal{H}$ with prob $1-\delta$, it suffices that:
$$n = O_{\gamma,\delta}(D)$$

**Conclusion:**
For a given hypothesis class $\mathcal{H}$, the number of training examples needed to achieve generalization error close to the optimal classifier is roughly linear in the VC dimension of $\mathcal{H}$. For most reasonable parameterizations, the VC dimension is roughly linear in the number of parameters.
